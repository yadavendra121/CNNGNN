CNN3DGNN: Hybrid 3D U-Net with Dynamic Semantic Region Graph for Low-Dose CT Segmentation

Overview

CNN3DGNN is a hybrid 3D CNN–GNN framework for robust low-dose CT segmentation.

The model combines:

3D U-Net backbone (local texture modeling)

Dynamic Semantic Region Graph Neural Network (global object reasoning)

Multi-head graph attention

Class-aware fusion gating

Auxiliary organ presence supervision

Contrastive node embedding learning

Deep supervision

This architecture is designed specifically for:

Noisy low-dose CT

Weak boundaries

Multi-organ interactions

Long-range anatomical reasoning

Loss Function Used

L=L_Dice + L_Focal + 0.5L_Boundary + 0.1L_AuxPresence + 0.1L_Contrastive
	​
Components:

Dice Loss → segmentation overlap

Focal Loss → class imbalance

Boundary Loss → contour refinement

Auxiliary Presence Loss → object-level supervision

Contrastive Loss → node consistency

Model Description
Encoder:

3D U-Net with 4-5 levels (adjust accordingly)

Bottleneck:

Dynamic Semantic Region GNN:

Attention-based graph

Object-to-object reasoning

Class-aware gating

Uncertainty-guided fusion

Outputs:

Model returns:

out, aux_logits, node_features, node_labels


Where:

out → segmentation prediction

aux_logits → organ presence prediction

node_features → node embeddings (contrastive)

node_labels → semantic pooled labels
